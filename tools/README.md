# tools

## reel-maker.html — Instagram縦型動画エディタ「リールメーカー」

ブラウザだけで動く、Instagram用（9:16）縦型動画の作成ツール。外部ライブラリなし・単体で動作。

### 使い方
`tools/reel-maker.html` をブラウザ（Chrome/Safari最新版推奨）で開くだけ。インストール不要。

### できること
- **素材**：動画 + BGM を読み込み（全画面切り抜き／全体表示）
- **長さ調整（トリミング）**：使う範囲を切り取り、投稿上限（フィード/ストーリーズ 60秒 / リール 90秒）内かを表示・自動切り詰め
- **テキスト構成**
  1. オープニング（上/中/下段・中央やや上）
  2. 流れるテロップ（本編・画面下を右→左へマーキー）
  3. エンディング（映像の上にお礼など）
  4. お礼（動画のあとに追加する専用画面・確実に最後に表示）
- **仕上げ**：映像とBGMのフェードイン／フェードアウト
- **書き出し**：MP4（対応環境）またはWebMで保存。プレビューから長押し/右クリック保存も可

### 注意
- 書き出しは実時間で録画（動画の長さ＝処理時間）。完了までタブを切り替えない。
- 音声を鳴らすため、最初の再生／書き出しは画面タップ（クリック）が必要。
- 出力形式はブラウザ依存。MP4対応ならInstagramにそのまま投稿可。
